PlacementHire
Campus placement platform · Full-stack · AI

PlacementHire

Problem
Campus placements involve students, colleges, faculty and recruiters on disconnected tools, so credentials are hard to trust and applications are hard to track.
Solution
One platform for all of them, with college-verified certificates and structured recruitment workflows. Designed for 1 lakh+ students.
Key features
  • Five roles with server-side authorization: Student, Recruiter, Faculty, College Admin, Platform Admin
  • Certificates approved by the college, a job-eligibility engine and application tracking
  • “Hire” AI assistant on Google Gemini, plus a placement-prediction ML model (80.2% accuracy, measured on my test set)
  • 1,390 automated tests passing in the latest run
My contribution
Founder and solo developer. Designed and built the product end to end, from schema and APIs to UI and deployment.

CareerAI

Problem
Placement readiness is hard to measure across skills, resume and academics, and it is unclear which gaps to fix first.
Solution
A client-side analyser that scores readiness across skills, resume, academics and job-role fit, and recommends next steps.
Key features

  • Job-role suitability scoring with logic-driven recommendations
